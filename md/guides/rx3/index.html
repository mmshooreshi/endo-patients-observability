Routes

  • IV: hospital only
  • Inhalation: N₂O sedation

Dosage Forms

  • Tablets / capsules → adults
  • Syrup / suspension → pediatrics
  • Mouth rinse → plaque / surgery
  • Gels → localized pain
  • ER / EC → never crush
