1. Diagnosis FIRST

  • No diagnosis = No prescription Critical
  • Swelling ≠ always infection
  • Pain ≠ always antibiotic indication
FindingThinkAction
Localized abscessOdontogenic infectionDrain ± Antibiotic
Diffuse swelling + feverSpreading infectionAntibiotic + referral
White oral lesionFungal?Antifungal, not antibiotic

2. Treatment Plan

Drug Only

Mild infection, no systemic signs

Surgery Only

Drainable abscess, no systemic spread

Both

Abscess + swelling + pain

Refer

Trismus, airway risk, immunocompromised

4. Routes

  • Oral: default route
  • Topical: chlorhexidine, gels
  • IM: severe swelling when oral not possible
  • IV: hospital only
  • Inhalation: nitrous oxide sedation

5. Forms

  • Tablets / capsules → adults
  • Syrup / suspension → pediatrics (shake well)
  • Mouth rinse → plaque, surgery care
  • Gel / ointment → localized pain
  • ER / EC → special instructions
